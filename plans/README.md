# Plans

Detailed, step-specific plans for individual items on `../todo.md`.

Convention: one file per non-trivial step, named `<todo-item-slug>.md`. Not every
todo item needs a file here — only ones substantial enough to need their own
design notes, options considered, or an implementation checklist. `todo.md`
links to a file here once it exists; if a todo item has no link, its plan
hasn't been written yet.
